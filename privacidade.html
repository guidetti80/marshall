Política de privacidade do Marshall

Atualizada em 28 de outubro de 2026.

O que é

O Marshall é um assistente pessoal que roda no computador do seu dono, para uso privado. Não é oferecido ao público.

Quais dados do Google ele acessa

Somente os eventos da agenda do Google, com a permissão de leitura calendar.events.readonly. Ele lê data, horário, título, local e se o convite foi respondido. Ele não cria, não altera e não apaga eventos.

Para que usa

Para mostrar ao próprio dono a agenda do dia e montar o resumo da manhã. Os dados não são usados para publicidade, não são vendidos e não são compartilhados com terceiros.

Onde ficam

A autorização do Google fica guardada no cofre de senhas do Windows, no computador do dono. Os eventos são lidos na hora e o texto do resumo do dia é salvo apenas nesse computador. Nada é enviado para servidores do Marshall: não existem servidores do Marshall.

Uso de dados do Google

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como revogar

A qualquer momento, em myaccount.google.com → Segurança → Apps de terceiros com acesso à conta → Marshall → Remover acesso. Os resumos salvos no computador podem ser apagados pelo dono.
